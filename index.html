🐄 MifugoHubTrack Setup

Connect this system to your Google Sheet database. You only need to do this once.

1
Open Google Sheets, create a new blank spreadsheet, and name it MifugoHubTrack Database
2
Click Extensions → Apps Script. Delete any existing code, paste the full contents of Code.gs, then click Save.
3
In Apps Script, click Run → setupSheets to create all database sheets. Authorise when prompted.
4
Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and copy the URL.
5
Paste that URL below and click Connect.
This URL connects the app to your Google Sheet. It stays in your browser only.
